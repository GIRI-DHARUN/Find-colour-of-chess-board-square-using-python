Find the square color of a chess board

==================================================

Example:
Enter a Square (like a1, b2,....): b4
Black square

==================================================

Logic used:
- Converting column letters (a-h) to numbers (0-7)
- Converting row numbers (1-8) to numbers (0-7)
- Adding row + column 
- If sum is even -> Black
- else if sum is odd -> White
